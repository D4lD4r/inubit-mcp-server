# T033 – review round 2

**Verdict: APPROVED** (2 minor findings, fixed by the orchestrator after approval)

## Round-1 findings

1. (major) Record-directory guard bypassable by links: fixed. The value is resolved via the
   nearest existing ancestor's real path; repository and any git working tree
   (`GitFreeTempDir.insideGitTree`, now public) are refused. Offline cases cover links, a case
   variant, a clone and a worktree `.git` file.
2. (major) Masked originals were not checked against the raw variables file: fixed. The
   originals come from the raw `.wfsp` via `WfspParser`, matched by position, and are checked
   against the log and the result.
3. (minor) Known scrubber secrets were not checked: fixed.
4. (minor) Short values: 4 to 9 characters are matched as tokens; the test fails when no helper
   run was observed.

## New findings

1. (minor) `recordDirectory` walks up from the unnormalized path; with a `..` after a missing
   component or a link, the real path can differ from the lexical one (for example
   `<outside>/missing/../link-into-repo/x`).
   Fix: `..` segments are refused outright (lexical normalizing would itself be wrong after a
   link). Offline test `aRecordDirectoryWithDotDotSegmentsIsRefused` (five paths); the two
   older tests that used `..` paths now use plain ones.
2. (minor) No case pins that the raw file is compared against `totalCount` rather than the
   returned items.
   Fix: `theRawFileIsMatchedAgainstTotalCountNotAgainstTheReturnedItems` (totalCount 4,
   3 items, 4-variable `.wfsp`).
