  - 0 → value
  - 44 → not found
  - 128 and 51 → access denied
  - 36 and 50 → store not available
  - any other code → access denied
  
  These match the low bytes of the OSStatus values: −25300 → 44, −128 → 128, −25293 → 51, −25308 → 36, −25294 → 50. The `0x` hex form is decoded case-insensitively and as strict UTF-8; malformed input → INVALID_VALUE with no bytes in the detail. A quoted run of hex digits stays text.
