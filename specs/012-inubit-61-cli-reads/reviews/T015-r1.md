It connects to the URL's host and port (443 if no port is given), using the node `timeout` as both the connect timeout and the read timeout. It sends the host name as SNI, setting it explicitly for names without a dot and leaving it out for IP literals. Endpoint identification `HTTPS` is on unless `disableHostnameVerification` is set. Every error carries the node id. `TIMEOUT` goes slightly beyond the task line, but follows the node-timeout requirement and is reasonable.
